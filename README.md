# FurEver Care

**They Deserve Forever Love**

A complete frontend-only pet-care portal built according to the FurEver Care SRS.

## Technologies
HTML5, CSS3, Bootstrap 5, Vanilla JavaScript, JSON, Fetch API, HTML5 Geolocation API, JavaScript Date API, Google Maps Embed.

## No Backend
No React, Angular, Vue, Node.js, PHP, database, Firebase, Supabase or server-side storage is used.

## Run
Because JSON is loaded with `fetch()`, open the project through a local static server rather than `file://`.

Example with VS Code Live Server:
1. Open the `FurEver-Care` folder.
2. Start Live Server.
3. Open `index.html`.

## AI Assets
No AI-generated image files are included in this starter build. Visual pet placeholders use emoji/CSS so there is no undisclosed AI asset usage.

## Data
All dynamic sample data is in `/data` and is read-only from the website. User profile data is only stored temporarily in sessionStorage for the current browser session.
